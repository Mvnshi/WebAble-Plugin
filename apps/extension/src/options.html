WebAble settings

The accessibility tools work with no setup. AI features are optional.

Appearance

The panel theme and read-aloud voice sync across the devices you are signed into Chrome on (chrome.storage.sync). Per-site tool settings and your AI key stay on this device (chrome.storage.local). A key is a credential, so it does not roam.

AI assist (optional)

Add a Google Gemini API key to enable alt-text generation, plain-language rewrites, page summaries, and Guide. The key is stored on this device only (chrome.storage.local), never synced to your other browsers, and is sent only to Google. WebAble has no server to log it to. If you use WebAble on more than one machine you will need to paste the key on each. Get a key at aistudio.google.com.

No key set.

What WebAble does

The same tools appear on every site, in the toolbar popup, and in the on-page menu (open it with the toolbar button or Ctrl/Cmd+Shift+U). Settings are remembered per site.

Sites you have turned WebAble off on

The tools do not run on these at all. Everything you had set for them is still saved and comes back when you turn them on again.

Move your setup to another computer

Save everything you have set up as a file: every site's tools, your defaults, your "fix this site" rules, the panel theme, and the sites you have turned WebAble off on. Open it on another computer, or on someone else's, to give them the same setup.

Your Gemini key is never in the file. It is a credential, and a settings file gets emailed and copied around. Enter it again on the other computer.

Data

Remove every WebAble preference from this device (per-site settings and the Gemini key), and the synced panel theme from every device you are signed into. This cannot be undone.
