WebAble widget, test harness

Each page embeds the production loader (/widget.js) and lazy-loads the functional chunk (/webable/boot.js). Open one, then use the launcher in the corner. Verify: it mounts, styles stay isolated, the page layout is untouched, features apply and revert, settings persist across reload, and it survives DOM mutations.

  • 1 · Plain static HTML, semantic article, images, a form.
  • 2 · Tailwind page, utility CSS, custom accent + position via data-*.
  • 3 · Bootstrap page, heavy framework + aggressive resets (isolation stress test).
  • 4 · Dynamic / SPA, content injected after load + infinite scroll (MutationObserver test).

Keyboard: Alt+Shift+A toggles the panel. Esc closes it.
