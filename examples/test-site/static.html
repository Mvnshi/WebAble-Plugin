The quiet craft of accessible interfaces

A sample article · 4 min read

Good accessibility is mostly invisible. It shows up as a page that simply works: links you can find, text you can resize, motion you can stop. This page exists to test those adjustments against plain, framework-free HTML.

Reading comfort

Try the reading tools: scale the text, switch to a readable or dyslexia-friendly font, loosen spacing, or turn on the reading mask. This sentence is set in a deliberately low-contrast gray to test the contrast and custom-color tools.

Color and motion

Invert the page, push contrast, or drop to grayscale. None of it should touch this widget's own panel, which lives in a shadow root.
