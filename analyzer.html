What this is — and isn't.

This analyzer runs local heuristics against the site you're currently viewing. It surfaces likely accessibility problems and tells you what to fix.

It does not claim WCAG compliance. It does not modify the site. It does not phone home. Compliance is a process; a button can't grant it. (See: FTC v. accessiBe, Jan 2026.)

A note on automated audits

Automated tools catch roughly 30-40% of accessibility issues (WebAIM, ongoing). The remaining 60-70% — keyboard traps, screen-reader experience, plain-language, color meaning — only manual testing with real assistive tech finds. WebAble's audit is a starting point, not a substitute for testing with users.
