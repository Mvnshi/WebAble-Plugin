What this server does

Mints subscriptions via Stripe Checkout (POST /api/checkout/create) and lets users manage them in the Stripe Billing Portal (POST /api/billing/create).

Proxies Gemini calls for paying users (POST /api/ai/*) — your GEMINI_API_KEY is the one that gets billed, never the user's.

Verifies Stripe webhooks at POST /api/webhooks/stripe with the signing secret — invoices, plan changes, cancellations all sync into the user database automatically.

Setup checklist

See STRIPE_SETUP.md in the repo root for step-by-step. TL;DR:

  1. Create a Stripe account, copy sk_test_… to .env
  2. Create a Product + two Prices (monthly + annual), paste their IDs in .env
  3. Get a Gemini API key from ai.google.dev, paste in .env
  4. npm install && npm start
  5. For local dev: stripe listen --forward-to localhost:8787/api/webhooks/stripe
  6. Open the WebAble extension → Settings → Account → "Connect to my server" → enter the URL of this server
